# 考研专注室

一个不联网的番茄钟，单文件网页，双击就能用。

## 里面有什么

番茄钟本身很普通：25 分钟专注，5 分钟短休，四个番茄之后长休，时长都能自己改。

不普通的是旁边那间屋子。桌上坐着一个人，你专注的时候她在写字，休息的时候她也歇着。
每完成一个番茄，桌上那盆绿植就长大一点。攒下的钻石可以往鱼缸里添条鱼——鱼会自己吐钻石，
养大了卖掉更划算——也能给她买顶帽子、给桌角添个杯子。

六个场景，从深夜书桌一直到星际舱，等级到了自动解锁。每个场景有自己的配色、家具和光源。

顶栏能切四档色调：深夜、黄昏、晨光、白天。不喜欢黑底就换一个。

环境音是现场算出来的，不是播放音频文件。雨、篝火、风、咖啡馆、键盘、夜虫六条，
各自有音量条，也能按场景一键配好。另外还有一段随机生成的 lofi，四个和弦轮着走，
旋律每次都不一样。

剩下的是些常规东西：复习进度勾选、每日任务、便签墙、每天一句、24 个成就、14 天专注图表。

## 怎么用

网页版打开就能用。想要离线，下载 `index.html`，双击用浏览器打开，功能一模一样。

Windows 上想要独立窗口和独立数据，下载 `KaoyanFocus.exe`，双击运行。记录会存在
`%APPDATA%\KaoyanFocus` 里。

数据全部保存在本机浏览器，不联网、不上传。底部有导出备份，换设备导进去就行。

## 关于实现

没有后端，所以一切都得在本地跑完。环境音和背景音乐全部是 Web Audio 现场合成的，
仓库里一个音频文件都没有。页面是单个 HTML，无框架、无 CDN、无构建步骤。

界面用 SVG 手绘，六个场景加起来不到 500 行。
